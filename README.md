# Harmony — Neuroinclusive E-Commerce Mobile App Design

**Harmony** is a neuroinclusive e-commerce mobile application designed to provide a calm, non-overwhelming, and accessible shopping experience for users with sensory sensitivities and neurodivergent traits (such as ADHD, Autism, and sensory overload).

### 🌟 Key Design Features:
- **Sensory-Friendly Interface:** Soft color palettes, minimal distractions, and customizable themes (Calm/Focus Mode).
- **Sensory Filters:** Search and filter products by texture, material, sound level, and tagless clothing.
- **Stress-Free Checkout:** Clear, simple flow without urgency timers or aggressive marketing banners.
- **Inclusive Onboarding:** Personalizable experience tailored to individual sensory preferences.

### 📱 Deliverables:
This repository contains the high-fidelity UI wireframes and user flow screens for the **Harmony** mobile app.
